Download **TempMail-OTP-Hub-Setup.exe** for Windows 10/11 (64-bit).

Run the installer and open TempMail OTP Hub from the Start menu. No Go, Python, Node.js, or additional runtime installation is needed. The dashboard opens in your default browser. Keep the app's console window open while using it; close that window to stop it.

Prefer no installation? Extract **TempMail-OTP-Hub-Windows-x64.zip** and double-click **tempmail-hub.exe**.

- Fixed the launcher referencing a missing executable.
- Credentials are saved under `%APPDATA%\TempMail-OTP-Hub` and survive updates and uninstall.
- The dashboard listens only on your computer and selects another port if 8585 is occupied.
- Internet access is required for the external temporary email providers.
- The executable and installer are unsigned.

GitHub's automatically generated source-code archives are for developers; use the installer or portable ZIP above.
